## التنفيذ المتسلسل

1. إغلاق P0: بيئة اختبار PostgreSQL، مهاجرات واستعادة وافتتاح محاسبي متفق عليه.
2. إغلاق عيوب المحاسبة والتتبع ثم فحوص lint/build واختبارات السيناريوهات المالية.
3. قبول العميل على Staging: عقد ومستخلص واعتماد وتحصيل؛ مقاول وصرف وعكس؛ شراء واستلام وسداد جزئي؛ عهدة وتسوية؛ راتب وسلفة؛ أدوار ومرفقات وتقارير.
4. توثيق مرجع الإصدار المعتمد، النسخ والاستعادة، ثم نشر الإنتاج وفحص الدخان ومطابقة أول يوم تشغيل.

## ما تحقق فعليًا بهذه الجولة

- قراءة مرجع المنتج وخطة التسليم وكود صفحة المحاسبة والترحيل وتاريخ البداية والمصادقة واختبار العزل.
- `pnpm exec tsc --noEmit` نجح على مساحة العمل الحالية.
- لم ينفذ build أو suite API أو اختبار اختراق أو فحص بصري شامل أو استعادة إنتاج في هذه الجولة؛ لا تسجل هذه البنود كناجحة.
- لم تعدل بيانات التشغيل أو تاريخ البداية، ولم تنفذ الإصلاحات المدرجة تلقائيًا ضمن طلب المراجعة.
